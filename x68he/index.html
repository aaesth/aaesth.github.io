Not connected

Plug in the keyboard, then press Connect keyboard and pick X68HE from the browser's list. Changes are saved on the keyboard.

This browser has no WebHID. Use Chromium, Chrome, Brave or Edge. Firefox cannot talk to USB keyboards.
The keyboard isn't listed, or it fails to open on Linux

Linux restricts raw access to the keyboard. Run this once, then unplug and replug the keyboard:

echo 'KERNEL=="hidraw*", ATTRS{idVendor}=="3151", ATTRS{idProduct}=="502d", MODE="0660", TAG+="uaccess"' \
  | sudo tee /etc/udev/rules.d/99-x68he.rules
sudo udevadm control --reload
sudo udevadm trigger --subsystem-match=hidraw --action=add
Click a key to change what it does.

Hold with:

Applies to this profile. Empty fields stay as they are on each key. Keys labelled DKS, MT, TGL or Snap use a mode set in the vendor driver; their mode is left alone.

While recording, keys you press are captured with their timing. Assign a macro on the Keymap tab. The keyboard has no erase command, so a used slot can be replaced but not emptied.

    A backup holds all 4 profiles, both Fn layers, macros, actuation and lighting. Restoring only writes what differs. It switches through the profiles and returns to the current one.
